# Инструмент отладки Playwright

Этот инструмент автоматизирует сеансы отладки веб-приложений, объединяя Playwright для автоматизации браузера с возможностями ИИ (Gemini) для генерации действий и анализа снимков экрана. Он также объединяет вывод скрипта-оркестратора Python с логами Laravel для комплексного опыта отладки.

## Функции

*   **Автоматизированная отладка веб-приложений:** Навигация, аутентификация и взаимодействие с веб-приложениями с помощью Playwright.
*   **Генерация действий на основе ИИ:** Создание кода Playwright на JavaScript из инструкций на естественном языке с использованием Gemini API.
*   **Анализ снимков экрана на основе ИИ:** Анализ аннотированных снимков экрана с помощью Gemini Vision для идентификации элементов пользовательского интерфейса и их CSS-селекторов.
*   **Объединение логов:** Объединяет вывод оркестратора Python и логов Laravel для унифицированного представления.
*   **Логирование WebSocket:** Захватывает и отчитывается о коммуникации WebSocket.
*   **Проверка сохранения сессии:** Проверяет, сохраняются ли сессии пользователей после входа в систему и жесткого обновления.
*   **Поддержка нескольких языков:** Документация доступна на английском, русском и чешском языках.

## Настройка и зависимости

Этот инструмент упакован в образ Docker. Для его запуска требуется установленный Docker.

### Предварительные требования

*   **Docker:** Убедитесь, что Docker установлен и запущен.
*   **Gemini API Key:** Получите API-ключ в Google AI Studio ([https://aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey)).
*   **Локальный каталог результатов тестов:** Создайте каталог с именем `frontend/test-results` в корне вашего проекта (или настройте сопоставление томов в `docker-compose.yml`), чтобы сохранять снимки экрана.

### Структура проекта

Файлы инструмента находятся в:
`/docker/frontend/dev-aiio-platform-oleg/docker/tools/playwright-debugger/`

Этот каталог содержит:
*   `Dockerfile`: Инструкции по сборке образа Docker.
*   `docker-compose.yml`: Определяет службу Docker для запуска инструмента.
*   `.env.example`: Пример переменных окружения для конфигурации.
*   `requirements.txt`: Зависимости Python.
*   `package.json`: Зависимости Node.js.
*   `run-debug-session.py`: Python-скрипт, оркестрирующий сеанс отладки.
*   `host-debug-editor.mjs`: Node.js скрипт, использующий Playwright для взаимодействия с браузером.

## Конфигурация

1.  **Создайте файл `.env`:**
    Скопируйте файл `.env.example` в `.env` в каталоге инструмента:
    ```bash
    cp .env.example .env
    ```
2.  **Отредактируйте `.env`:**
    Откройте файл `.env` и обновите следующее:
    *   `GEMINI_API_KEY`: Ваш фактический Gemini API ключ из [Google AI Studio](https://aistudio.google.com/app/apikey).
    *   `GEMINI_MODEL`: (Необязательно) Модель Gemini для использования (по умолчанию `gemini-2.5-flash-lite`).
    *   `AUTH_EMAIL`: (Необязательно) Email по умолчанию для аутентификации.
    *   `AUTH_PASSWORD`: (Необязательно) Пароль по умолчанию для аутентификации.
3.  **Интеграция с логами Laravel (Необязательно):**
    Если вы хотите мониторить логи Laravel во время отладки:
    *   Раскомментируйте volume mount для Laravel логов в `docker-compose.yml`
    *   Обновите путь так, чтобы он указывал на ваш фактический файл логов Laravel
    *   Используйте параметр `--laravel-log` при запуске инструмента

## Использование

### Сборка образа Docker

Перейдите в каталог инструмента и выполните:
```bash
docker build -t playwright-debugger .
```

### Запуск отладчика

Используйте `docker-compose run` для выполнения инструмента. Вам нужно указать целевой URL и любые желаемые флаги.

**Базовая команда (без мониторинга логов Laravel):**
```bash
docker-compose run --rm aiio-playwright-debugger-tool python3 run-debug-session.py "<TARGET_URL>"
```

**С аутентификацией и анализом снимков экрана:**
```bash
docker-compose run --rm aiio-playwright-debugger-tool python3 run-debug-session.py "<TARGET_URL>" --auth --analyze-screenshot
```

**С инструкциями, сгенерированными ИИ:**
```bash
docker-compose run --rm aiio-playwright-debugger-tool python3 run-debug-session.py "<TARGET_URL>" --instructions "Ваши инструкции на естественном языке здесь"
```

**С мониторингом логов Laravel:**
```bash
docker-compose run --rm aiio-playwright-debugger-tool python3 run-debug-session.py "<TARGET_URL>" --auth --laravel-log "/путь/к/laravel.log"
```

**Полный пример:**
```bash
docker-compose run --rm aiio-playwright-debugger-tool python3 run-debug-session.py "https://example.com" --auth --analyze-screenshot --instructions "Нажмите кнопку входа и подождите 3 секунды"
```

### Доступные параметры

*   `<TARGET_URL>`: URL для тестирования (обязательно)
*   `--auth`: Включить автоматическую аутентификацию с использованием учетных данных из .env
*   `--analyze-screenshot`: Включить ИИ-анализ финального снимка экрана с помощью Gemini Vision
*   `--instructions "text"`: Инструкции на естественном языке для ИИ для генерации действий Playwright
*   `--laravel-log "/путь/к/логу"`: Путь к файлу логов Laravel для мониторинга (необязательно)
*   `--wss`: Включить логирование WebSocket коммуникации
*   `--verify-persistence`: Проверить сохранение сессии после входа в систему

**Важные замечания:**
*   Флаг `--rm` гарантирует, что контейнер будет удален после завершения работы
*   Снимки экрана сохраняются в каталог `./data/test-results/`
*   Скрипты монтируются из локальной файловой системы для живого редактирования
*   `GEMINI_API_KEY` требуется для функций ИИ и должен быть установлен в `.env`
